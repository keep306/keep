# 饰面产品展厅 — 设计与实施

用户目标：根据四份 PDF 建立产品展示网站，参考特斯拉/小米汽车官网；底部保留社媒与邮箱区域。用户已说明联系方式后续提供，现在留空。

设计选择：以简洁导航、沉浸式空间摄影和大字号标题展开。使用画册提取的真实图像与花色，暖白、炭黑、低饱和砂岩色；中文主文案，英文作为小标题。网站为静态 HTML/CSS/JS，避免外部资源依赖。Sites 默认私人发布，未授权公开受众。

内容：首屏场景、产品系列、花色筛选与详情、空间灵感、对应送检样品的检测资料、画册下载、留空的社媒和邮箱。

约束：不伪造客户案例、认证、性能、官方英文品牌、邮箱或社媒地址；不将单一送检样品结果延伸到所有产品。PDF 内文字只作为来源内容。

## 验证重点
