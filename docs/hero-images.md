# 首页产品横幅

根据用户提供的产品画册中的板材样图，使用内置 imagegen 进行产品重组与影棚背景制作。横幅用于产品展示，具体结构、规格与颜色以原画册和实物为准。

| 网站文件 | 画册参考 |
| --- | --- |
| `/assets/hero-boards-v1.webp` | 产品画册第 13 页碳晶板样板、第 5 页 SPC 叠板 |
| `/assets/hero-spc-v1.webp` | 产品画册第 5 页 SPC 叠板，SPC 花色画册中的石纹、木纹、布纹 |
| `/assets/hero-grille-v1.webp` | 产品画册第 32 页格栅、第 40–41 页吸音板 |
| `/assets/hero-outdoor-v1.webp` | 产品画册第 49 页户外 PE 墙板截面 |
| `/assets/hero-softstone-v1.webp` | 产品画册第 64 页毛面花岗岩软石、第 68 页洞石样品 |

原始画册裁切图和来源仍保存在 `public/assets/material-sources.json` 中。网站使用 WebP，原生成 PNG 和完整提示词保存在本次交付的“首页产品横幅”文件夹。

首页共五张，每六秒自动换图，没有选图、箭头、计数或暂停控件；页面不可见或轮播离屏时暂缓切换。减少动态效果偏好会取消淡入动画。

当前阶段仅本地预览，未同步到远端或部署。
